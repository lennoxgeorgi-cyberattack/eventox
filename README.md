# Map Mates Event Finder

baue eine webapp, das prinzip besteht darin: man kann auf einer open street map events in der nähe in deutschland finden, besonders für kleine dorffeste und veranstaltungen ist das sinnvoll, man kann events auch in einer liste aufgelistet finden, ausserdem kann man events favorisieren und freunde hinzufügen wo man sehen kann welche die favorisieret haben. man kann filtern nmach radius um den eigenen standort durch einen schieberegler, nach datum und nach kategorie der veranstaltung. die app soll eventox heissen, ein türkises thema haben und liquid glass interface haben, ausserdem kann man selbst events hinzufügen und auch goldene pins für 10€ kaufen, die sichtbarer sindf, es soll auch am boden platz für etwas google adsense werbung sein, die app soll handy optimiert sein.
